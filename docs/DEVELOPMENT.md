# Tunex — для разработчиков

Настройка Windows для игр: электропитание, игровые функции, системные твики, сеть, настройки для отдельных игр, экран, мониторинг и проверка производительности.

## Сборка

Нужна только Windows 10/11 — .NET Framework 4.8 и компилятор уже встроены.

```
build.cmd
```

Результат: `bin\Tunex.exe` — один файл, его можно копировать на другие ПК. Перед сборкой закройте запущенный Tunex.

### Установщик для друзей

```
build-setup.cmd
```

Результат: `dist\Tunex-Setup.exe` — его и отправляйте. Установщик даёт выбрать папку (по умолчанию `%LOCALAPPDATA%\Programs\Tunex`, без прав администратора; для `Program Files` сам попросит права), создаёт ярлыки и запись в «Приложения и возможности», откуда Tunex удаляется как обычная программа.
Тихая установка: `Tunex-Setup.exe /silent /dir "D:\Games\Tunex"` (`/nodesktop`, `/nostartmenu`). Тихое удаление: `Uninstall.exe /uninstall /quiet`.
Версия — `Theme.Version` в `src\Core.cs` и `Version` в `tools\Setup.cs`.

### Выпуск новой версии (автообновление)

Tunex сам проверяет последний выпуск на GitHub (раздел «Настройки» → «Автообновление») и подменяет свой файл; новая версия открывается при следующем запуске.
1. Поднять номер версии: `Theme.Version` в `src\Core.cs` и `Version` в `tools\Setup.cs` (например, `0.2`).
2. Собрать `build.cmd` (и `build-setup.cmd` для новых друзей).
3. На GitHub: Releases → Draft a new release → тег `v0.2` → приложить `bin\Tunex.exe` (имя файла должно быть ровно `Tunex.exe`) и, по желанию, `dist\Tunex-Setup.exe` → Publish.
Адрес репозитория — `Updater.Repo` в `src\Updater.cs`. Репозиторий должен быть публичным, иначе у друзей обновление не скачается.

Цвет акцента выбирается в разделе «Оформление» (3 готовых или свой), сохраняется в `state.json`.

## Как устроено

| Файл | Что внутри |
|---|---|
| `src/Core.cs` | Тема (цвета, шрифты), WinAPI, реестр, сведения о ПК |
| `src/Ui.cs`, `src/Ui2.cs` | Элементы интерфейса: карточки, сетка настроек, окно описания, верхний блок дашборда, окно проверки |
| `src/Tweaks.cs` | Все настройки (каталог с текстами), снимки «как было», применение, откат, журнал |
| `src/Extras.cs` | Службы, очистка памяти, сеть (EEE, DNS), файл подкачки, приоритет фоновых процессов |
| `src/Apps.cs` | Программы рядом с игрой: Discord (аппаратное ускорение), состояние оверлея NVIDIA |
| `src/PcCheck.cs` | Вкладка «Оценка ПК»: подробные характеристики (память по слотам, диски, драйверы, экраны) и правила «Скрытых проблем»: монитор не на той частоте или в разъёме материнской платы, игры на HDD при наличии SSD, драйвер (нет, отключён, ошибка, старый), XMP и каналы памяти, питание (батарея, экономия заряда, режим энергоэффективности), выключенный файл подкачки, Wi-Fi при свободном разъёме. Скрытые проблемы (`Finding.Hidden`) показывает и «Главная» — проверка идёт в фоне |
| `src/GameReq.cs` | Игры в «Оценке ПК»: установленные игры Steam, системные требования из магазина Steam (кэш в `%APPDATA%\Tunex\steam`, 14 дней), таблица процессоров, сравнение с ПК |
| `src/FpsData.cs` | 20 популярных игр и типичный FPS на опорной системе (RTX 3060 + Core i5-12400, Full HD) — числа примерные, правятся здесь; пересчёт под другие видеокарты и процессоры |
| `src/Backup.cs` | Бэкапы: снимок всех настроек в `%APPDATA%\Tunex\backups` (последние 15 + «как было до Tunex»), сравнение с текущими, восстановление с записью в журнал; автоматически раз в день перед первым изменением и перед каждым восстановлением |
| `src/Updater.cs` | Автообновление: последний выпуск из GitHub Releases, скачивание и подмена `Tunex.exe` (старый файл — `Tunex.exe.old`, удаляется при запуске) |
| `src/Bench.cs` | Проверка производительности: процессор, память, диск |
| `src/Fps.cs` | Замер FPS через Intel PresentMon 2.6.0: скачивание с проверкой SHA-256 в `%APPDATA%\Tunex\tools`, запись кадров, средний FPS, 1% и 0,1% низкие, рывки, запись за всю игру. Нужны права администратора |
| `src/FpsPage.cs` | Раздел «Замер FPS»: замер по кнопке (отсчёт 10 с) или по Ctrl + Shift + F9, сравнение с прошлым замером, график, история; окно «Итог игры» после закрытия игры из списка |
| `src/Play.cs` | «Перед игрой»: какие программы занимают память и процессор, закрытие (как крестиком, без потери данных) и возврат после игры; пинг до серверов CS2 и Dota 2 (открытый список Valve, кэш в `%APPDATA%\Tunex\net`, 7 дней), для Valorant — до дата-центров Amazon в тех же городах, плюс пинг до роутера; «Не беспокоить»: уведомления (WNF) и пауза обновлений Windows на сутки с возвратом |
| `src/PlayPage.cs` | Раздел «Перед игрой»: разгрузка, автоматический режим для игр из списка, пинг с итогом простыми словами |
| `src/Lag.cs` | «Разбор лагов»: запись последних 2 минут раз в секунду (все процессы одним вызовом `NtQuerySystemInformation` — процессор, чтение и запись, память, ошибки страниц, новые процессы; занятость каждого диска), разбор последних 40 секунд перед нажатием (диск, память, процессор и кто его занял, перегрев, проснувшиеся обновления и Защитник, видеокарта на пределе), хранение разборов в `%APPDATA%\Tunex\lags.json` (последние 30) |
| `src/LagPage.cs` | Раздел «Разбор лагов»: Ctrl + Shift + F10 из игры или кнопка «Разобрать сейчас», график за 2 минуты, причины с советами, все разборы |
| `src/LoadTest.cs` | Пинг под нагрузкой (bufferbloat): пинг до 1.1.1.1 в покое, во время скачивания и во время отправки (сервис скорости Cloudflare, 4 потока по 8 с, в память), итог и советы по настройке роутера; показывается в «Перед игрой» |
| `src/Care.cs` | «Обслуживание»: частота опроса мыши по сырому вводу (Raw Input), очистка места (временные файлы старше недели, скачанные обновления Windows, отчёты о сбоях, остатки загрузок Steam, кэш шейдеров — выключен по умолчанию; ссылки на другие папки не трогаются), автозагрузка из Run и папок «Автозагрузка» с отметкой StartupApproved, как в Диспетчере задач, время загрузки и замедления из журнала Diagnostics-Performance |
| `src/CarePage.cs` | Раздел «Обслуживание»: проверка мыши, очистка, автозагрузка с переключателями |
| `src/Sensors.cs` | Датчики: ЦП, ОЗУ, видеокарта, температура |
| `src/Displays.cs` | Мониторы: яркость/контраст (DDC/CI), гамма, частота |
| `src/Pages.cs` | Разделы приложения |
| `src/MainForm.cs` | Окно, меню, применение настроек, слежение за играми |
| `src/Logo.cs` | Логотип (он же иконка) |

**Добавить новую настройку** — одна запись в `Catalog.Build()` в `src/Tweaks.cs`: заголовок, короткое описание, подробности и рекомендация (`All` — красная метка, `Some` — жёлтая, `Optional` — серая).

Состояние (журнал, исходные значения, игры, результаты проверок) хранится в `%APPDATA%\Tunex\state.json`.

## Проверки

```
bin\Tunex.exe --selftest report.txt
```
Применяет и откатывает безопасные настройки (прозрачность, ненужные службы) и проверяет, что каждая настройка читается.

```
tools\bin\Verify.exe report.txt
```
Запускать от администратора. Для каждой настройки проверяет, что Windows реально даёт её изменить: записать → прочитать → вернуть. Сетевую карту не перезапускает.

Для просмотра интерфейса: `Tunex.exe --page games`, `--tweak game.gamebar`, `--wizard`, `--bench`, `--fpssummary` (окно итога для последнего замера), `--pcdemo` (выдуманный ПК со скрытыми проблемами в «Оценке ПК» и на «Главной»), `--page prep --ping` (сразу замерить пинг), `--bottom` (прокручивать раздел вниз каждые 4 с в течение 32 с), `--page prep --load` (сразу проверить пинг под нагрузкой), `--page lag --lagdemo` (выдуманный разбор лага), `--page care --mouse` (сразу начать проверку мыши).
Чтобы проверять на копии настроек, задайте папку состояния: `set TUNEX_STATE_DIR=C:\temp\tunex-test`.
Новая версия PresentMon: поменять `Version`, `Url`, `Size` и `Sha256` в начале `src\Fps.cs`.

## Иконка

Рисуется кодом в `src/Logo.cs`. После правок: `tools\make-icon.cmd` → обновятся `app.ico` и `icon-preview.png`, затем `build.cmd`.

Цвета интерфейса — в начале `src/Core.cs` (класс `Theme`).

## Дизайн

Сейчас — v3 «Стекло» по образцу GlassWise UI (скилл в `.claude/skills/glasswise-ui`): светлая и тёмная тема (выбор в «Оформлении»: как в Windows, светлая, тёмная), голубое свечение в левом верхнем углу окна, почти белые карточки со скруглением 14 px, круглые кнопки, системные цвета iOS, шрифт Segoe UI, подписи обычными буквами. Включённый переключатель — зелёный, сплошной акцент — только у главной кнопки.
Цвета обеих тем — `Theme.SetMode` в `src\Core.cs`; фон со свечением — `Theme.PaintBackdrop`, карточка — `Theme.PaintCard`.

Прежние дизайны: v2 «Приборная панель» (графит, лайм, острые углы) — в `design-backup\v2-dashboard`, бирюзовый v1 — в `design-backup\v1-teal` (исходники, иконка и готовый exe).
`restore-old-design.cmd` возвращает v1 — текущие файлы перед этим сохраняются в `design-backup\before-restore`.
