# GlassWise UI

Готовый набор из трёх файлов в папке `assets/glasswise/` рядом с этим файлом:
- `tokens.css` — переменные цветов обеих тем, шрифт, скругления, тени, каркас;
- `components.css` — компоненты с приставкой `gw-`;
- `glasswise.js` — тема, бегунок переключателей, меню, окно снизу, уведомление, своя полоса прокрутки, плавная прокрутка.

Образец всех компонентов — `assets/demo.html`. Прочитай его перед вёрсткой: там правильная разметка каждого компонента.

## Как подключать

1. Скопируй `tokens.css`, `components.css`, `glasswise.js` в проект, в папку `glasswise/` (или куда принято в проекте для статики). Не переписывай их своими словами — копируй как есть.
2. В `<head>`: два `<link rel="stylesheet">` и `<script src=".../glasswise.js">` (скрипт в head, чтобы тема встала до отрисовки).
3. `<body class="gw">`.
4. В React, Vue и т. п. — подключи CSS глобально, скрипт — один раз; после перерисовки переключателей вызывай `GW.seg()`.

## Правила (соблюдать всегда)

- Цвета — только переменные из `tokens.css` (`--card`, `--label`, `--label2`, `--fill`, `--blue`…). Своих цветов не заводить. Подписи не светлее `--label2`.
- Сплошной синий — только главное действие экрана (`gw-btn main`). Выбранный пункт, вкладка, метка — `--tint` с синим текстом.
- Кнопки круглые; карточки со скруглением 12–14 px, лёгкой тенью `--shadow`; разделители тонкие (`.5px var(--sep)`).
- Подписи разделов — `gw-sec`, обычными буквами, без заглавных.
- Иконки — inline SVG (stroke 1.6–1.8, `currentColor`), без эмодзи.
- Нет системных `<select>`: кнопка `gw-dd` + `GW.menu()`. «Да / нет» — `gw-switch`.
- Настройки — `gw-grp` со строками `gw-opt`; отдельные записи — `gw-cards`; список — `gw-list`.
- Страница с навигацией — шапка `gw-top` и каркас `gw-layout` (колонка `gw-aside` слева, `gw-main` справа).
- Удаление — без `confirm()`: сразу удалить и показать `GW.toast('…', { action: 'Вернуть', onAction })`.
- Движение 0,2–0,3 с, кривая `var(--ease)`; уважать `prefers-reduced-motion`.
- Нужен новый компонент — собери его из токенов в том же духе и дай класс с приставкой проекта, а не `gw-`.

## Проверка

Открой страницу в светлой и тёмной теме (`GW.theme.set('dark')`) и на ширине телефона (375 px): текст читается, ничего не вылезает по ширине.
